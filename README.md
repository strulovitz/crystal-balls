# Crystal Balls

Crystal Balls forecasts the coming week's news for 31 influential countries
and shows the result as three transparent globes nested inside each other,
like matryoshka dolls: the inner globe is the situation two rounds ago, the
middle globe is the previous round, and the outer bright globe is the
forecast for the coming week.

Live page: https://www.strulovitz.org/crystal-balls/

Full specification: see the `BIBLE/` folder, starting with
`BIBLE/part-00-mission.md`.
