How Crystal Balls works

This page is a placeholder. The full marketing page explaining the project — the method, the three nested globes, and how the scoring works — is written later (Bible Part 6, section 6.3 notes this page is "written later").

In short

Crystal Balls reads this week's headlines for 32 countries from 12 news sources, asks a local AI to describe what happened (the "position"), how it changed since last week (the "velocity"), and how far off last week's forecasts were (the "wind"). It then asks for two forecasts for the coming week: a plain one from headlines alone, and a "Crystal" one that also uses the trend and the correction. Every forecast is graded automatically once the following week's news comes in, using the Brier score (lower is better; always guessing 50% scores 0.25).

Everything is free, open source, and runs on a home computer. The code and all the data are on GitHub.
